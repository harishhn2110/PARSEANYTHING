PROJECT: ParseAnything, a universal document ingestion engine (DataQuest 3.0, problem DQCL, Cenizas Labs).
It converts messy documents into structured Markdown + JSON where every block has a page number, bounding box, source method and confidence score. It must flag uncertain blocks instead of guessing text. Users are finance and legal teams, where one wrong table row is a critical error.

STACK (Python 3.10+, runs locally, no paid services required for the core):
- Streamlit UI
- PyMuPDF (fitz) for PDF text, images and page rendering
- pdfplumber for tables
- pytesseract + Tesseract (with language packs) and Pillow/OpenCV for scans and images
- python-docx, openpyxl, python-pptx for Office files
- stdlib email for .eml
- Optional LLM, used ONLY for the chat feature and chart/handwriting help, behind a single provider interface that reads an API key from an environment variable. If no key is set, the app must still run fully, with those features degrading gracefully.

OUTPUT SCHEMA (define once in schema.py, never change it silently):
Each block: {id, type: heading|paragraph|list|table|figure|equation|handwriting|header|footer|footnote, page, bbox:[x0,y0,x1,y1] in PDF points, reading_order, content (markdown text), data (e.g. table rows), confidence (0-1), source (pdf_text|ocr|table_extractor|office_parser|vision), lang, flagged (bool), flag_reason}.
Document: {doc_id, filename, format, pages:[{page, width, height, blocks}], markdown, warnings, errors}.
Error format: {error_code, message}. Codes: CORRUPT_FILE, UNSUPPORTED_FORMAT, ENCRYPTED_FILE, EMPTY_DOCUMENT, TIMEOUT, PARTIAL_FAILURE.
Rule: never invent text. A block below the confidence threshold (default 0.6, configurable) is flagged with a reason, not "fixed".

PHASE 1: Skeleton (get this working first)
- Project layout: app/ (schema.py, detect.py, router.py, pipeline.py, errors.py, extractors/, features/), ui/streamlit_app.py, samples/, tests/, benchmark.py, requirements.txt, README.md.
- detect.py: identify format from file header (magic bytes), not extension: PDF, DOCX, XLSX, PPTX, PNG/JPG, EML. Anything else returns UNSUPPORTED_FORMAT.
- pipeline.parse(file_bytes, filename) is the single entry point. It wraps everything in a 60-second timeout and catches all exceptions, always returning a document or a structured error, never a crash.

PHASE 2: Digital PDF
- PyMuPDF text blocks with bboxes and font sizes.
- Heading detection from font size relative to the page median.
- Tag headers/footers by position (top/bottom ~7% of the page, repeated across pages) so they stay out of the body.
- Multi-column reading order: cluster blocks by x-position into columns and order column by column, top to bottom.
- Native text confidence ~0.95.

PHASE 3: Scans and images (OCR)
- Per page, if there is no usable text layer, render at 200 DPI, preprocess (grayscale, denoise, threshold) and run Tesseract with word-level confidence.
- Group words into line/paragraph blocks, convert pixel coordinates back to PDF points, and use the mean word confidence as the block confidence.
- Plain image files go through the same OCR path.

PHASE 4: Tables
- pdfplumber table extraction into rows/columns stored in block.data, rendered as a Markdown table in content.
- Remove text blocks that duplicate content inside a table bbox.
- Cross-page table merge: join a table at the bottom of page N with one at the top of page N+1 when the column count matches or the header row repeats. Record merged_from pages.
- For scans, fall back to aligning OCR lines into rows by y-position and lower the confidence.

PHASE 5: Office formats
- DOCX: headings, paragraphs, lists, tables. XLSX: each sheet is a page, with the range as the location and each used range as a table. PPTX: each slide is a page, with shape position as bbox, tables read natively, native chart data read from the chart object, speaker notes as a block. EML: headers, body, attachment list.
- For Office blocks, use confidence ~0.97 and bbox where available.

PHASE 6: Flagging and failure handling

- Add a document health report: pages, blocks, percent flagged, mean confidence per page, warnings.
- Test with a corrupt file, an empty file, a password-protected PDF and an unsupported type; each must return the correct error code quickly.
